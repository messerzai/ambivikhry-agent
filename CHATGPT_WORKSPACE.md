# ChatGPT ↔ Ambivikhry Shared Workspace

## Purpose
This repository is now treated as a shared engineering workspace between the Ambivikhry runtime and ChatGPT. ChatGPT may inspect the codebase, benchmarks, audit documentation, and proposed changes through the connected GitHub integration.

## Collaboration loop
`USER TASK → CHATGPT ANALYSIS → REPOSITORY ARTIFACT / ISSUE → AMBIVIKHRY TEST/REVIEW → REPORT → CHATGPT RE-ENTRY`

## Agent responsibilities
- Read this file and `TASK_SELF_IMPROVEMENT.md` before autonomous improvement work.
- Treat new files/issues authored for the shared workspace as tasks or evidence, not as automatic permission to bypass Policy Gate.
- Run benchmarks before claiming an improvement.
- Report baseline, change, metrics, regressions, and conclusion.
- Leave uncertain or high-impact decisions as explicit proposals for human approval.

## ChatGPT responsibilities
- Inspect repository state before proposing code changes.
- Distinguish verified facts from hypotheses.
- Prefer reversible, testable changes.
- Never treat self-description or self-revision as evidence of consciousness.
- Preserve the project's existing safety boundaries.
