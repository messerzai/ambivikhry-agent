# АМБИВИХРЬ / КВИН-ВОРТЕКС v2.6.0

Саморевизующийся агентный runtime: reasoning loop, verifier, tools, audit memory и контролируемая репликация.

> **Цель:** создавать полезные, правдивые и безопасные системы, которые помогают людям. Протокол не является заявлением о наличии у агента сознания или самостоятельной личности.

## Цикл

**Задача → Ж → Л → Центр → Верификация → Решение → Policy Gate → Действие → Наблюдение → Реэнтри ↺**

- **Ж** — расширяет пространство кандидатов.
- **Л** — перерабатывает конфликт и отделяет факты от предположений.
- **Центр** — удерживает неизвестное и условия пересмотра.
- **Верификация** — проверяет структуру утверждений; внешние факты должны подтверждаться внешними источниками/инструментами.
- **Реэнтри** — результат витка влияет на следующий.

## Возможности v2.6

- структурированный JSON-план;
- консервативный verifier;
- Tool Registry;
- Policy Gate перед побочными эффектами;
- Dry Run по умолчанию;
- `state.json` + `audit.jsonl`;
- ограниченный агентный цикл и stop conditions;

- regression tests и GitHub Actions для Python 3.10–3.13.

## Запуск без внешнего API

```bash
python -m pip install -e .
ambivikhry-demo
```

Демо использует `MockLLM` и не выполняет внешних действий.

## Подключение OpenAI-compatible API

Секреты не помещаются в код или репозиторий:

```bash
export AMBIVIKHRY_API_KEY="..."
export AMBIVIKHRY_BASE_URL="https://api.openai.com/v1"
export AMBIVIKHRY_MODEL="your-model"
```

Затем передайте `OpenAICompatibleLLM()` в `AmbivikhryAgent`.

## Безопасность

Репликация не распространяется по сети, потомок не запускается автоматически, привилегии не повышаются. Высокорисковые или требующие подтверждения инструменты блокируются без явного approval. Саморевизия не считается доказательством истины.

**Новая версия не считается улучшением без тестируемого изменения.**
