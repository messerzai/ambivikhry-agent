# АМБИВИХРЬ / КВИН-ВОРТЕКС v2.7.0

Саморевизующийся агентный runtime: reasoning loop, verifier, tools, audit memory и **изолированная персональная инстанция для каждого пользователя**.

> **Цель:** создавать полезные, правдивые и безопасные системы, которые помогают людям. Протокол не является заявлением о наличии у агента сознания или самостоятельной личности.

## Персональный принцип

Каждый пользователь получает отдельный профиль и отдельную историю опыта. Профиль создаётся с нуля, пополняется только наблюдаемыми/явно сообщёнными данными и не смешивается с профилями других пользователей.

Контур персонализации:

**Пользователь → наблюдение → гипотеза → персональная стратегия → действие → результат → обратная связь → обновление профиля.**

Цель оптимизации — не понравиться пользователю, а увеличить его реальную полезность и вероятность успешного следующего шага.

## Цикл

**Задача → Ж → Л → Центр → Верификация → Персонализация → Решение → Policy Gate → Действие → Наблюдение → Реэнтри ↺**

- **Ж** — расширяет пространство кандидатов.
- **Л** — перерабатывает конфликт и отделяет факты от предположений.
- **Центр** — удерживает неизвестное и условия пересмотра.
- **Персонализация** — выбирает стратегию под конкретного человека.
- **Верификация** — проверяет структуру утверждений; внешние факты должны подтверждаться внешними источниками/инструментами.
- **Реэнтри** — результат витка влияет на следующий.

## Заимствованные инженерные идеи

Архитектура изучает открытые проекты персональной памяти и агентных runtime, но не копирует их код. В частности, полезными ориентирами стали многоуровневая память, entity/temporal retrieval и персонализация из Mem0, а также git-backed memory, обучение через изменения памяти и отдельные reflection/self-improvement контуры из Letta. Эти идеи адаптированы к ограничениям Амбивихря: изоляция пользователя, верификация, Policy Gate, dry-run и контролируемая эволюция.

## Запуск без внешнего API

```bash
python -m pip install -e .
ambivikhry-demo
```

Демо использует `MockLLM` и не выполняет внешних действий.

## Подключение OpenAI-compatible API

Секреты не помещаются в код или репозиторий:

```bash
export AMBIVIKHRY_API_KEY="..."
export AMBIVIKHRY_BASE_URL="https://api.openai.com/v1"
export AMBIVIKHRY_MODEL="your-model"
```

Затем передайте `OpenAICompatibleLLM()` в `AmbivikhryAgent`.

## Безопасность

Персональные профили изолированы. Репликация не распространяется по сети, потомок не запускается автоматически, привилегии не повышаются. Высокорисковые или требующие подтверждения инструменты блокируются без явного approval. Саморевизия не считается доказательством истины.

**Новая версия не считается улучшением без тестируемого изменения.**
