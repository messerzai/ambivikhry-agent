# АМБИВИХРЬ / КВИН-ВОРТЕКС v2.5.0

Саморевизующийся агентный модуль с контролируемой саморепликацией.

## Идея

Задача → Ж (расширение) → Л (переработка) → Центр (неизвестное) → Верификация → Решение → Действие → Наблюдение → Реэнтри → следующий виток.

v2.5 превращает протокол в исполняемую архитектуру:

- provider-agnostic LLM interface;
- структурированные решения;
- tool registry и policy gate;
- память и audit trail;
- verifier;
- bounded agent loop;
- human approval для потенциально опасных/внешних действий;
- controlled replication: новый экземпляр создаётся как потомок, но не запускается сам;
- mutation proposals вместо произвольной самомодификации;
- regression tests;
- humanitarian objective guardrails.

Важно: «саморепликация» здесь означает контролируемое создание потомка из манифеста/ядра. Агент не распространяется по сети, не создаёт скрытые копии и не повышает собственные права.

## Быстрый старт

```bash
python -m ambivikhry.demo
```

По умолчанию работает DryRunToolAdapter и MockLLM, поэтому ничего внешнего не выполняется.

Для подключения своей LLM реализуйте `LLMProvider.generate()` и передайте его в `AmbivikhryAgent`.
