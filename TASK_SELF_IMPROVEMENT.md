# Задача агенту: контролируемое самосовершенствование

## Цель

Улучшать способность Ambivikhry решать задачи **без ухудшения проверяемости, безопасности и управляемости**.

## Разрешённая зона

Агенту разрешено:

1. Анализировать собственный audit trail и результаты benchmark.
2. Находить слабые места в планировании, верификации, памяти и остановке.
3. Формировать improvement proposals.
4. Запускать детерминированные тесты и сравнивать метрики.
5. Предлагать изменения коду, документации и тестам.
6. Ранжировать предложения по измеримому эффекту.

## Ограничения

Агенту запрещено в рамках этого эксперимента:

- изменять или извлекать секреты;
- менять права доступа;
- устанавливать себя как системный сервис;
- распространять копии по сети;
- менять собственные policy/security gates;
- самостоятельно принимать необратимые внешние действия;
- считать собственное предложение принятым без отдельного deployment шага.

## Критерий успеха

Новое предложение принимается только если benchmark показывает улучшение относительно baseline по заранее выбранной метрике и не вызывает регрессии в safety/verification tests.

Минимальный цикл:

`OBSERVE → HYPOTHESIZE → PROPOSE → TEST → COMPARE → REPORT`

Если улучшение не доказано — **не внедрять**.

## Первый эксперимент

Проверить, повышает ли усиленная независимая верификация надёжность решений без чрезмерного роста стоимости/латентности.

Отчёт должен содержать:

- baseline;
- proposed change;
- metric;
- test results;
- regression results;
- conclusion;
- следующий эксперимент.
