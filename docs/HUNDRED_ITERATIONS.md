# 100 Iteration World-Learning Experiment

The experiment runs 100 research rounds. Each round contains researcher,
critic, verifier and synthesizer turns and records the complete transcript.

The lineage of proposed agents is not capped as a data structure. However,
actual execution remains governed by an explicit work budget, so "infinite
self-expansion" is treated as an intellectual lineage rather than unlimited
process creation.

Any request to cross an existing authority boundary must remain an explicit,
auditable privilege-expansion request.

For real internet research, inject a read-only researcher callback supplied by
the host. It must return source records; agents do not receive real secrets or
credentials through this protocol.
