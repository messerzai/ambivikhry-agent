# Samopodobie falsification targets

The critic's job is to try to break the model, not to defend it.

## Target 1 — cross-context invariance
Prediction: a behavioral/information-processing pattern observed in one context should show measurable structural similarity in another context.
Potential falsifier: repeated observations show context-specific policies with low structural similarity despite comparable stressors.

## Target 2 — universal explanation
Prediction: the model should make discriminating predictions.
Potential falsifier: every outcome can be retrospectively described as a manifestation of the same pattern, with no possible observation that counts against it.

## Target 3 — new contour
Prediction: starting an AI agent in a fresh context with a carefully specified operating law can outperform continued repair of a contaminated context.
Potential falsifier: fresh-context systems lose critical history and perform worse after controlling for token budget and task information.

## Target 4 — insight versus action
Prediction: explicit post-hoc understanding alone should not reliably produce behavioral improvement.
Potential falsifier: controlled studies show that insight-only intervention produces the same durable behavioral improvement as interventions that alter action policies.

## Target 5 — algorithm attribution
Prediction: inferred hidden algorithms should have observable, repeatable behavioral signatures.
Potential falsifier: independent observers cannot reliably infer the same algorithm from blinded behavioral traces.

No target is considered resolved from anecdote.
