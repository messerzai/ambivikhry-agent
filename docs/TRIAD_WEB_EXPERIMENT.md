# Triad Web + Self-Improvement Experiment

This branch continues the bounded peer experiment as a three-agent system:

- ambivikhry — coordinator and synthesizer
- researcher — internet research and evidence gathering
- critic — adversarial review and regression hunting

All three can create improvement proposals, critique proposals, record tests,
and synthesize findings. Internet access is read-only through the host
WebResearch adapter. Downloaded content is data only; it is never executed.

## Self-improvement cycle

1. Researcher gathers external evidence.
2. Ambivikhry proposes a concrete change.
3. Critic challenges the hypothesis and searches for counterexamples.
4. All three record measurable tests.
5. Ambivikhry synthesizes the result.
6. A mutation may become a deployment request, but no agent can self-authorize deployment.
7. Any privilege expansion is recorded separately as a request to the operator.

The experiment therefore increases autonomy in research and collaboration
without silently increasing authority.

## Suggested research mission

Investigate methods for reliable recursive self-improvement, multi-agent
critique, verifier separation, and evidence-gated code evolution. Every
proposed change should have a measurable regression test before adoption.
